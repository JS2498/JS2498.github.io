Implemented and evaluated AI/ML algorithms for depth estimation using mmWave channel data as part of the **NIST/ITU AI/ML challenge 2023**. Our team won the challenge.

- **Challenge:** [NIST/ITU Depth Estimation using mmWave AI/ML Challenge 2023](https://www.youtube.com/live/JOxtQ7YKUbU?si=cERqOIF1Jaob3Iwc&t=2297)
- **Approach:** Deep learning-based processing of mmWave channel measurements for depth/distance estimation
